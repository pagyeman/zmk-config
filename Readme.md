# ZMK Configuration for Corne Bluetooth Keyboard

ZMK configuration using Workman DH as a basis and adding separate layers for brackets, numbers, arrow-keys, and mouse movements.
The implementation has separate layers for workman dh, brackets, and numbers for macOS and windows. In both cases relying on a Swiss German keymap as the point of reference.
Bluetooth band 0 is bound to the mac and automatically switches to layer 0, while Bluetooth band 1 is bound to my work laptop, a windows machine, and automatically switches to layer 5.
The Bluetooth and layer switching is orchestrated with a macro.
